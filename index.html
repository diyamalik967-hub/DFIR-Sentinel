About this project

Project synopsis and operating limitations.

DFIR Sentinel — Digital Forensics and Incident Response System

This academic prototype demonstrates a basic DFIR workflow: ingesting authorised security logs, applying transparent detection rules, registering evidence, calculating SHA-256 hashes and preparing an investigation report.

Objectives

  • Analyse security log records.
  • Identify repeated failed login attempts and potential brute-force activity.
  • Track incidents and investigation status.
  • Calculate SHA-256 hashes for evidence integrity checks.
  • Generate a report for documentation.

Technology

HTML, CSS and JavaScript with the browser File API and Web Crypto SHA-256 interface. This self-contained version requires no server, account or paid subscription.

Important limitations

This is a demonstration tool, not a commercial forensic suite. It does not monitor a device live, inspect iOS internals, perform memory forensics, enrich IP reputation from the internet, or preserve court-grade chain of custody. Use only data you own or are authorised to analyse. All analysis is performed locally in the browser; uploaded files are not sent to a server.
